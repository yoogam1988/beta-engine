修复 2: Checkbox 标签关联

修复 4: 删除确认输入框

已修复
✕修复前
<label>请输入应用名称</label><input type="text" />
✓修复后

修复 5: Checkbox 键盘事件优化

已优化
// 修复前 - 冗余的条件判断
if (event.key === ' ' || event.key === 'Enter') {
  if (event.key === ' ') event.preventDefault()
  onCheck?.(event)
}

// 修复后 - 简化处理
if (event.key === ' ' || event.key === 'Enter') {
  event.preventDefault()
  onCheck?.(event)
}
  • 统一处理 Space 和 Enter 键的默认行为
  • 代码更简洁，可读性更好

✨ 修复总结

本次修复共处理 5 个 UX/可访问性问题，涵盖输入框标签、Checkbox 关联、按钮语义化、 表单无障碍和键盘事件优化。所有修复均遵循 WCAG 2.1 AA 标准，确保残障用户可以使用 Screen Reader 和键盘导航完整使用 Dify 应用。
